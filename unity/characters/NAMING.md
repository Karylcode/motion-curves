# 動作命名規範

每支動作要有：中文名稱（`label`）、英文 Animator 狀態名（`en`）、類型（`type`）、描述（`description`）、四欄固定標籤（`tags`）。網頁選單照「武器 → 類型」排序，每列顯示中文名稱，後面用淡色字顯示原檔 id。

## 中文名稱格式

```
類型・姿態・方向（差異）
```

- 各段用「・」（全形中點）分隔，沒有的段就省略。
- **類型**一定放最前面，只能用下表的詞。
- **姿態**只能用下表的詞。待機、走路、小跑、跑步、轉身、射擊、換彈這七種類型一定要寫姿態，站著的寫「一般」。其他類型不寫姿態。
- **方向**一律以角色自己為準：前、後、左、右、左前、右前、左後、右後。轉身寫「左 90°」「右 180°」，角度取最接近的 45 的倍數。幾種類型的這一段寫法不同：
  - 閃避：寫閃開那一步的方向（閃完通常會回原位，所以標籤的位移是「原地」），例如「閃避・左後」。
  - 受擊：寫被打的位置：左側、右側、頭部、腹部（原檔 Hit_L、Hit_R、Hit_Upper、Hit_Low；Upper 是頭被往後甩、Low 是上身往前折）。
  - 倒下：寫倒的方向：向前、向後。
  - 取出、收起：寫武器放的位置：背後（Back）、腰後（LowerBack）。
  - 邊走邊射：「射擊・一般・前（左手槍）」，姿態照身體寫，再加移動方向。
- **差異**放在全形括號裡，只在同一個角色有兩支名稱會一樣時才加，寫最短、看得出差別的詞。例如「走路・瞄準・左（前交叉）」「走路・瞄準・左（後交叉）」。
- **攻擊、技能**的格式是「攻擊 1：特徵」「技能 1：特徵」。編號照原檔 id（Attack_1、Attack_01 都寫 1），冒號是全形「：」，特徵 12 個中文字以內，寫揮砍的方向、次數、身體大動作，例如「右上往左下斜斬」「突進三連斬接上撩」。
- **表情**的格式是「表情・生氣」。
- 同一個角色裡名稱不能重複。

### 類型（`type` 欄位也用這個詞）

| 類型 | 英文 | 用在 |
|---|---|---|
| 待機 | Idle | 原地站著、架式、跪著、瞄準不動（循環） |
| 走路 | Walk | 走路速度移動（循環） |
| 小跑 | Jog | 介於走和跑（平均速度約 1.5～3 m/s，騰空很短或沒有） |
| 跑步 | Run | 跑步，有明顯騰空 |
| 衝刺 | Sprint | 比跑步快、身體大幅前傾 |
| 轉身 | Turn | 原地轉向 |
| 快速移位 | QuickShift | 短距離快速滑步、跨步換位置 |
| 閃避 | Evade | 躲開攻擊的動作（含翻滾、後跳、側閃） |
| 攻擊 | Attack | 一般攻擊（原檔 Attack_N） |
| 技能 | Skill | 特殊技（原檔 Sp_Skill_N） |
| 射擊 | Shoot | 開槍 |
| 換彈 | Reload | 換彈匣、裝彈 |
| 受擊 | Hit | 被打到的反應 |
| 暈眩 | Stun | 暈眩搖晃（循環） |
| 倒下 | Die | 死亡倒地 |
| 取出 | Draw | 拔劍、拔刀、從背後或槍套拿出武器（原檔 Take、TakeGun） |
| 收起 | Holster | 收劍、收刀、把武器收回去（原檔 Put、PutGun） |
| 表情 | Emote | 表情動作（生氣、打招呼…） |

### 姿態

| 姿態 | 英文 | 意思 |
|---|---|---|
| 一般 | （不寫） | 一般站姿，不是戰鬥架式 |
| 架式 | Stance | 戰鬥架式：屈膝側身壓低（原檔 Sp_、SP_） |
| 蹲姿 | Crouch | 彎腰壓低移動或蹲著，膝蓋沒著地 |
| 跪姿 | Kneel | 單膝或雙膝著地 |
| 瞄準 | Aim | 舉槍瞄準 |
| 蹲姿瞄準 | CrouchAim | 蹲姿＋舉槍瞄準 |
| 跪姿瞄準 | KneelAim | 跪姿＋舉槍瞄準 |

原檔叫 Crouch 的，膝蓋著地（數據表「膝蓋著地比例」≥ 0.4）就是跪姿，沒著地就是蹲姿。

## 英文 Animator 狀態名

```
類型_姿態_方向_差異
```

- 每段用英文字首大寫（PascalCase），段與段用底線。沒有的段省略，「一般」不寫。
- 方向：F、B、L、R、FL、FR、BL、BR；轉身寫 L90、R90、L180。
- 攻擊、技能用兩位數編號：`Attack_01`、`Skill_03`，不加特徵。
- 差異用簡短英文：`CrossFront`、`CrossBack`、`LeftGun`、`Auto`……
- 例：`Idle`、`Idle_Stance`、`Idle_Kneel`、`Walk_Crouch`、`Jog_Stance`、`Turn_Stance_L90`、`Walk_Aim_L_CrossFront`、`Walk_CrouchAim_F`、`QuickShift_B`、`Evade_BL`、`Hit_L`、`Hit_Head`、`Hit_Stomach`、`Die_F`、`Draw_Back`、`Holster_LowerBack`、`Shoot_F_LeftGun`、`Emote_Angry`。
- 每個角色有自己的 Animator，所以不加武器前綴。同一個角色裡不能重複。

## 描述

- 1～3 句，照時間順序：起始姿勢（武器怎麼拿、單手或雙手）、主要動作（揮砍或射擊的方向和次數、轉身方向和角度、有沒有跳起來）、位移（往哪移、多遠）、結束姿勢、是否循環。附關鍵數字。
- 方向以角色自己為準。用詞跟名稱一樣：寫「架式」不寫「架勢」，寫「蹲姿」「跪姿」不寫「低姿」「壓低」。
- 網頁這版武器一直固定在手上，但描述照動作本身寫，可以補「（原版此時收刀入鞘）」。
- 只根據數據和連拍圖判斷，不要編劇情。用繁體中文。

## 四欄固定標籤（`tools/naming-pack.py` 照數據自動算，不手改）

| 欄 | 可能的值 | 規則 |
|---|---|---|
| 姿勢 | 站姿、半蹲、深蹲、跪姿、倒地 | 結束時頭低於 0.5 m＝倒地；膝蓋著地 ≥ 40% 時間＝跪姿；骨盆高度中位數 ＜ 站直的 0.55＝深蹲、＜ 0.835＝半蹲；其他＝站姿 |
| 位移 | 原地、前、後、左、右、左前、右前、左後、右後 | Root 淨位移 ＜ 0.3 m＝原地，否則取淨位移方向（以角色一開始的方向） |
| 播放 | 循環、單次 | 原檔的 Loop Time |
| 手 | 單手、雙手、左右各持、空手 | 左手大部分時間（≥ 40%，倒地的格不算）握在主武器上，或揮主武器那幾格有四分之一以上握著＝雙手（刀劍看 0.15 m 內、槍看 0.28 m 內；刀身和左手的刀鞘疊在一起的格不算；雙刀、雙苦無、雙手槍、劍盾除外）；左手另外拿東西（第二把武器、盾、刀鞘）＝左右各持；表情＝空手；其他＝單手 |

覺得標籤跟連拍圖明顯不符時，不要改，寫在 `疑問` 欄。

## 資料（子代理用）

資料包在 `tools/naming-pack.py` 的輸出資料夾（派工時會給路徑）：

- `packs/<角色>.md`：這個角色每支動作的規則草稿、舊名稱、舊描述、重點數據、連拍圖路徑。
- `sheets/<id>_1.png…`：連拍圖。三列＝後方視角（畫面左＝角色左手邊）、右側視角（畫面右＝角色前方）、俯視（畫面上＝角色一開始的前方）。藍＝左半身、紅＝右半身、橘線＝臉朝向、綠＝第一把武器、紫＝第二把、淡色線＝上一格到這格武器尖端走過的路、腳下的色塊＝那隻腳踩地。格線 0.5 m，視角固定在角色一開始的方向（角色轉身時，後方視角會看到側面或正面）。
- `sheets/<id>_overview.png`：全程總覽。武器尖端軌跡由淺到深＝時間先後，數字＝連拍圖的格號；黑線＝骨盆路徑；灰＝開始姿勢、黑＝結束姿勢。
- `features_all.json`：全部動作的完整數據（移動、骨盆朝向、腳踩地、交叉步、膝蓋、手、武器揮動段落、槍口方向、標籤）。
- `unity/characters/<角色>.json`：武器、原版插槽切換（notes）。
- `unity/animators/<控制器>.json`（設定檔的 `animators` 有寫才有）：原版 Animator 的狀態名、原始 FBX 名、混合樹裡每支動作的位置（例如八方向走路）。
- 需要更細的數字時，可以讀 `public/motions/<id>/analysis.json`（關節角度、腳踩地）和 `angles.json`（2～10 MB，逐取樣的骨頭位置），用 node 或 `python -X utf8`。不要改 `public/motions/` 底下任何檔案。

## 交出

寫成一個 JSON 檔：

```json
{"<id>": {"type": "攻擊", "label": "攻擊 1：右上往左下斜斬", "en": "Attack_01", "description": "...", "疑問": ""}, ...}
```

涵蓋派給你的每一支。存到指定路徑（不要直接改 `public/motions/names.json`）。最後回報檔案路徑、支數、哪幾支跟規則草稿不同、哪幾支判斷不確定。
